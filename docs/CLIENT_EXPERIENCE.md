# Client experience

The Client journey starts on a personalised, photo-led Home screen. It links directly to property discovery, saved properties, bookings, messages, and notifications. Property discovery supports debounced search, server filters and sorting, pull-to-refresh, pagination, accessible favourite actions, cached Expo images, and explicit loading/empty/error states.

Property detail hides private address and coordinate data. Clients see a public location, listing facts, gallery, realtor identity, and similar properties. Only active listings accept new inspection bookings. Reserved, sold, and rented listings remain visible but show unavailable booking guidance.

Profile remains the fourth visible tab and contains account editing plus Saved, Bookings, and Notifications links. More is not a visible Client tab.
