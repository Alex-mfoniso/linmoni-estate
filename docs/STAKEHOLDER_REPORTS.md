# Stakeholder Reports Spreadsheet Schema Guide

This document catalogs the CSV schema, record types, and file outputs generated by the Stakeholder reporting engine.

---

## 📈 Spreadsheet Profiles

### 1. Properties Portfolio Export
*   **Filename**: `properties_report.csv`
*   **Endpoint**: `GET /api/v1/stakeholder/reports/properties`
*   **Description**: Compiled list of all properties across active, draft, and verification queues.
*   **Headers**:
    `ID,Title,Price,Status,PropertyType,ListingType,Realtor,City,State`

### 2. Brokers Performance Export
*   **Filename**: `performance_report.csv`
*   **Endpoint**: `GET /api/v1/stakeholder/reports/performance`
*   **Description**: Live performance metrics log for active Realtors in the brokerage.
*   **Headers**:
    `ID,Name,Email,Agency,Status`

### 3. Operations Velocity Export
*   **Filename**: `operations_report.csv`
*   **Endpoint**: `GET /api/v1/stakeholder/reports/operations`
*   **Description**: Snapshot of staff quality review queues and unresolved system incident counts.
*   **Headers**:
    `Metric,Value`

---

## 📁 Technical Export Handlers
*   **MIME Content-Type**: `text/csv`
*   **Content-Disposition**: `attachment; filename=<report_name>.csv`
*   **Line-Endings**: RFC 4180 standard CRLF (`\r\n`) with double-quote escaping for title boundaries containing commas.
